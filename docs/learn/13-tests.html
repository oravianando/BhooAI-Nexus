Key package suites

  • nexus-core — config, DI, http server/router.
  • nexus-auth — auth flow + security (CSRF/CORS/headers/rate limit).
  • nexus-data — ODM (schema, populate, transactions).
  • nexus-graphql — graphql, federation, subscriptions.
  • nexus-payments — providers against mocked HttpTransport.
  • nexus-cli — dotenv, config-sync, cli dispatch.
  • Every package also has its own tests/*.test.ts (telemetry, realtime, plugins, email, crypto, cache, ads, ai-client).

Backend integration

apps/backend/tests/*.integration.test.ts boot a real server on an ephemeral port against a real MongoDB and exercise auth, GraphQL, payments, certs, admin, subscriptions, and the AI proxy. They set the CSRF Origin header explicitly because APIRequestContext/fetch clients don't send one by default — the same reason the e2e does.

Python contract tests

apps/ai-server/tests/test_contract.py verifies the OpenAPI contract (chat, embeddings, models, provider routing) with a mocked httpx transport — runnable offline with pip install -r requirements.txt && pytest.

E2E happy path

// tests/e2e/nexus.e2e.spec.ts
health → CSRF → register (first user = admin) → /me
→ GraphQL query → payments error path

The Playwright global setup spawns tsx apps/backend/src/main.ts, drops a throwaway nexus_e2e DB, waits for /health, then runs the flow. Transient Windows socket errors are retried with backoff (ECONNREFUSED/ECONNRESET…) to keep the suite stable.

Running everything

npx vitest run                                      # Node unit + integration
pytest                                               # Python AI contract tests
npx playwright test --config=playwright.config.ts    # cross-service e2e

Playground

Sandbox: a mini assertion + retry-with-backoff model. Live API: health (the e2e's first step).
