Security @bhooai/nexus-auth is one cohesive security unit — CSRF, CORS, security headers, rate limiting, JWT sessions, RBAC, and OAuth — plus @bhooai/nexus-telemetry for logging.

Code walkthrough

1. CSRF — double-submit + origin check

Safe methods (GET/HEAD/OPTIONS/TRACE) get a fresh token cookie (nexus_csrf) and expose it via ctx.state.csrfToken. Unsafe methods must present an x-csrf-token header that matches the cookie, and the Origin must be trusted:

if (safeMethods.has(ctx.method)) {
  const token = issueToken(ctx, cookieName, cookieOpts);
  ctx.state.csrfToken = token;
  await next(); return;
}
checkOrigin(ctx, trusted);  // Origin/Referer must be trusted
const cookieToken = readCookie(ctx, cookieName);
const sentToken = ctx.headers[tokenName];
if (!cookieToken || !sentToken || !timingSafeEqual(cookieToken, sentToken)) {
  throw new AuthenticationError('Invalid CSRF token');
}
Loopback trust In Docker, published ports are remapped (e.g. :3001 → :3011). Loopback origins are trusted regardless of port; external origins match strictly. This was a real bug fixed during the build.

2. WebSocket CSRF

WebSockets have no CORS preflight, so the upgrade request verifies the token via the Sec-WebSocket-Protocol header against the cookie (checkWsUpgrade in csrf.ts).

3. Sessions + refresh-token rotation

AuthService.refresh validates the refresh token, then checks the session's currentJti. If a presented token's jti no longer matches, it was reused after rotation → the whole session family is revoked:

if (session.currentJti && payload.jti && session.currentJti !== payload.jti) {
  await this.sessions.destroyFamily(session.familyId);
  throw new AuthenticationError('Refresh token reuse detected; session revoked');
}

Each mintPair issues a fresh jti and stores it on the session, so the next refresh invalidates the previous refresh token (rotation).

4. JWTs

jwt.ts signs tokens with a kind discriminator (access vs refresh) so an access token can never be used to refresh. AuthService.verifyAccessToken rejects tokens whose kind isn't access.

5. RBAC + middleware

middleware.ts provides authToken(service, { required, cookieName }), requireAuth(), and requireRole('admin'). Route registration wires them as the 3rd array argument: router.get('/admin/...', handler, [authToken(...), requireRole('admin')]).

6. Telemetry (nexus-telemetry)

The Logger supports levels, pretty/file formats, redaction of keys like password/secret, and request/trace ids. MetricsRegistry tracks counters/histograms (e.g. http_requests_total).
