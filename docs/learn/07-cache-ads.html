Code walkthrough

1. Lazy Redis cache

The cache connects lazily on first use (ensureConnected), so a backend boots fine even when Redis is down — operations throw only when actually used:

async ensureConnected() {
  if (this.client.isOpen) return;
  if (!this.connectPromise) this.connectPromise = this.client.connect();
  try { await this.connectPromise; }
  catch (err) { this.connectPromise = null; throw err; }  // allow retry
}

Values are JSON-encoded; keys pass through key(name) for a namespace prefix.

2. Rate limiter + pub/sub

RateLimiter implements sliding-window limits over Redis — the production upgrade to the in-memory rateLimit middleware in nexus-auth. PubSub uses a dedicated subscriber client so it never blocks normal cache traffic.

3. GAQL builder

const query = new GaqlBuilder()

  .where("campaign.status = 'ENABLED'")

  .limit(50)
  .build();
