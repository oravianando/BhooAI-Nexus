Code walkthrough

1. Attach + upgrade

The server attaches to an HTTP server's upgrade event, only handling its own path. The upgrade is the security boundary — WebSockets have no CORS preflight, so CSRF is checked here:

if (url.pathname !== (this.opts.path ?? '/ws')) return;
if (this.opts.csrfOptions) checkWsUpgrade(req.headers, this.opts.csrfOptions);
const token = url.searchParams.get('token') ?? /* subprotocol */ '';
if (this.opts.authService && token) {
  const payload = await this.opts.authService.verifyAccessToken(token);
  userId = payload.sub; roles = payload.roles ?? [];
}

2. Rooms + fanout

Members per room are tracked per instance. Direct peer messages publish to conn:<id>; room events publish to room:<room>. With the Redis adapter, any instance delivers to its local members — that's how you scale across machines.

3. WebRTC signaling + SFU

Offer/answer/ICE-candidate messages are relayed through the room channel. The mediasoup adapter routes actual media; if the native worker isn't installed the adapter skips gracefully (documented seam).

4. In the backend

apps/backend/src/main.ts wires it:

const realtime = new RealtimeServer({
  httpServer: server.httpServer,
  path: config.ws.path,
  authService,
  csrfOptions: config.ws.requireCsrf ? { trustedOrigins: trustedOrigins(config) } : undefined,
});

Playground

Sandbox: a mini room + fanout model. Live API: there's no WS REST endpoint, so the API tab hits the backend health to confirm it's up — room broadcasts run over the WebSocket instead.
