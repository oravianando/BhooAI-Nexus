Data ODM @bhooai/nexus-data is a from-scratch Object-Document Mapper on the official mongodb driver. Schemas, validation, hooks, populate, indexes, transactions — no mongoose.

Code walkthrough

1. Connection

connect(uri, opts) creates a Connection (lazy MongoClient). Models register on a connection and their indexes are created on connect:

connect(config.db.uri, { name: dbName, autoIndex: config.db.autoIndex });
await getConnection().db;  // forces the driver to connect

2. Schema + validation

Schemas declare field types, defaults, hooks, statics, and indexes — e.g. the User model in apps/backend/src/modules/users/userModel.ts:

const userSchema = new Schema({
  email: { type: String, required: true, unique: true, match: /.+@.+\..+/, transform: (v) => String(v).toLowerCase() },
  passwordHash: { type: String, select: false },
  roles: { type: [String], default: () => ['user'] },
  oauthAccounts: { type: Array, default: () => [] },
}, { timestamps: true, collection: 'users' });
select: false passwordHash is excluded from normal queries — a real security default. Login uses a raw driver lookup (findUserForLogin) that requests the field explicitly.

3. Model — the write API

Model.create builds a new instance (_isNew = true), applies defaults, validates, then save() inserts. hydrate() marks _isNew = false for rehydrated docs. This new-vs-hydrate discipline was a real bug class caught during the build:

async create(docs) {
  const input = Array.isArray(docs) ? docs : [docs];
  const out = [];
  for (const data of input) {
    const instance = newInstance(this.schema, this, data);  // _isNew = true
    await instance.save();
    out.push(instance);
  }
  return out;
}

4. Query builder

Model.find().sort().limit().populate('author').lean().exec() — a fluent chain that builds a mongo cursor. populate is batched (one extra query per relation) to avoid N+1.

5. Transactions

transaction(fn) wraps a callback in a mongo session (session.withTransaction), used by payment flows.

Playground

Sandbox: model default/validation + a mini query chain. Live API: the GraphQL users query backed by the real ODM.
