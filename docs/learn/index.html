LEARN THE CODE

Build BhooAI Nexus Step-by-step walkthroughs of every module, every file, and the code that makes it work — with a live playground to run it.

This guide reconstructs the framework the way it is wired in apps/backend/src/main.ts: foundation first, then security, data, the Graph layer, realtime, commerce, AI, and operations. Each chapter explains the role of a package, maps every source file, and walks through the important code line-by-line.

Every chapter ends with an interactive playground. Use the JS sandbox tab to run browser-safe logic snippets, and the Live API tab to call a running Nexus backend on localhost:4000 (start it with node bin/nexus.js dev).

THE BUILD ORDER

Foundation → Intelligence

Each layer builds on the previous one. If you want the shortest path to "I understand this codebase", read chapters 1 → 4 → 8 → 11. For the full picture, read all thirteen.

Chapters

01 · Foundation

nexus-core — workspace, config, DI, errors, the custom HTTP server + trie router.

02 · Security

nexus-auth + nexus-telemetry — CSRF, CORS, JWT, OAuth, RBAC, logging.

03 · Data ODM

nexus-data — a from-scratch ODM on the MongoDB driver. No mongoose.

04 · GraphQL

nexus-graphql — subgraphs, federation, query planner, subscriptions. No Apollo.

05 · Realtime

nexus-realtime — WebSocket rooms, Redis fanout, WebRTC signaling, mediasoup SFU.

06 · Payments · Email · Crypto

Five gateways, webhook verification, SMTP + templates, keypairs + CSRs.

07 · Cache · Ads

nexus-cache Redis wrapper + rate limiter + pub/sub; nexus-ads GAQL client.

08 · AI Server

Python FastAPI + nexus-ai-client — OpenAI-compatible, SSE streaming, one contract.

09 · Plugins

nexus-plugins — manifest, trusted host, sandboxed workers, hooks, admin extensions.

10 · Cluster

nexus-cluster — node agents, registry, load balancer, autoscaler, AI advisor.

11 · CLI

nexus-cli — supervisor, init/dev/doctor, config-sync, project templates.

12 · Apps

The four terminals — backend bootstrap, frontend tabs, admin SPA, Docker.

13 · Tests

vitest suites, backend integration, Python contract tests, Playwright e2e.

14 · Postman API Testing

Step-by-step guide to testing the cluster link API with Postman — CSRF, JWT auth, screenshots, troubleshooting.
