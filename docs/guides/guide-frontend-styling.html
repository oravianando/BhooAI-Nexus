GUIDE

Frontend Styling Tailwind, PostCSS, and design tokens in scaffolded Nexus frontends.

Every project scaffolded with nexus init ships with a complete CSS pipeline: Tailwind utility classes, PostCSS processing, and a framework-wide design token system. This guide walks through how it fits together and how to customize it.

The CSS pipeline

Three files control the frontend styling in a scaffolded project:

FileRole
postcss.config.jsLoads the @bhooai/nexus-postcss preset — the plugin chain
tailwind.config.jsTailwind content scanning + theme extensions
src/index.cssCSS entry — @import theme tokens + @tailwind directives + custom styles

1. PostCSS config

The preset handles the entire PostCSS plugin chain. A scaffolded postcss.config.js is one line:

import { createPreset } from '@bhooai/nexus-postcss';

export default createPreset();

This loads 6 plugins in order: postcss-import → postcss-nested → tailwindcss → postcss-preset-env → autoprefixer → cssnano (production only). See the PostCSS API reference for all options.

2. Tailwind config

Each app keeps its own tailwind.config.js. The scaffolded default:

export default {
  content: ['./index.html', './src/**/*.{ts,tsx}'],
  theme: { extend: {} },
  plugins: [],
};

Extend the theme with your own colors, fonts, spacing, etc.:

export default {
  content: ['./index.html', './src/**/*.{ts,tsx}'],
  theme: {
    extend: {
      colors: {
        brand: '#67e8f9',
      },
    },
  },
  plugins: [],
};

3. index.css — the CSS entry point

The scaffolded src/index.css has four parts:

/* 1. Import framework design tokens */
@import '@bhooai/nexus-postcss/theme.css';

/* 2. Tailwind layers */
@tailwind base;
@tailwind components;
@tailwind utilities;

/* 3. Override tokens (optional) */
:root {
  /* --nexus-accent: #ff6b6b; */
}

/* 4. Custom CSS using tokens */
.nexus-card {
  background: var(--nexus-surface);
  border: 1px solid var(--nexus-border);
  border-radius: var(--nexus-radius);
  color: var(--nexus-ink);
  padding: 1.5rem;
  backdrop-filter: blur(20px);
}

.nexus-mesh-bg {
  background: var(--nexus-mesh), var(--nexus-bg);
  background-attachment: fixed;
  min-height: 100vh;
}

.nexus-link {
  color: var(--nexus-accent);
  text-decoration: none;
}
Order matters @import must come first (before @tailwind) so that postcss-import can inline the tokens. @tailwind base resets browser defaults; your custom CSS goes after it so it can override defaults.

Two ways to style: Tailwind utilities vs CSS classes

Nexus supports both approaches, and you can mix them freely:

Tailwind utility classes (in JSX)

function Card() {
  return (
    <div className="flex gap-4 p-6 bg-white rounded-lg shadow">
      <h2 className="text-xl font-bold text-slate-800">Title</h2>
    </div>
  );
}

Plain CSS classes (in index.css)

/* index.css */
.my-card {
  display: flex;
  gap: 1rem;
  padding: 1.5rem;
  background: var(--nexus-surface);
  border-radius: var(--nexus-radius);
}
/* App.tsx */
<div className="my-card">...</div>

Hybrid (recommended for Nexus apps)

Use Tailwind utilities for layout/spacing/typography, and Nexus tokens for colors/surfaces that need to stay consistent with the dark theme:

<div className="flex gap-4 p-6 rounded-lg"
     style={{ background: 'var(--nexus-surface)', color: 'var(--nexus-ink)' }}>
  ...
</div>

App structure: main.tsx + App.tsx

Scaffolded frontends separate the entry point from the app component:

// src/main.tsx — entry point
import React from 'react';
import { createRoot } from 'react-dom/client';
import './index.css';
import { App } from './App';

createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
// src/App.tsx — app component
import { useEffect, useState } from 'react';

export function App() {
  return (
    <main className="nexus-mesh-bg" style={{ padding: '2rem', minHeight: '100vh' }}>
      <div className="nexus-card" style={{ maxWidth: '32rem', margin: '0 auto' }}>
        <h1 style={{ color: 'var(--nexus-ink)' }}>My Nexus App</h1>
        <p style={{ color: 'var(--nexus-muted)' }}>Hello world</p>
      </div>
    </main>
  );
}

Customizing the PostCSS pipeline

Pass options to createPreset() to tune the pipeline:

import { createPreset } from '@bhooai/nexus-postcss';

export default createPreset({
  // Add framework admin source to Tailwind content scan
  extraContent: ['../../packages/nexus-admin/src/**/*.{ts,tsx}'],

  // Extend Tailwind theme
  theme: {
    colors: { brand: '#67e8f9' },
  },

  // Disable preset-env (use only Tailwind + autoprefixer)
  presetEnv: false,

  // Always minify (even in dev)
  minify: true,

  // Append a custom PostCSS plugin
  plugins: ['my-postcss-plugin'],
});

Adding @tailwindcss/forms or other Tailwind plugins

// 1. Install the plugin
npm install -D @tailwindcss/forms

// 2. Add to postcss.config.js
import { createPreset } from '@bhooai/nexus-postcss';
import forms from '@tailwindcss/forms';

export default createPreset({
  tailwindPlugins: [forms],
});

// 3. OR add to tailwind.config.js (both approaches work)
export default {
  content: ['./index.html', './src/**/*.{ts,tsx}'],
  theme: { extend: {} },
  plugins: [forms],
};
