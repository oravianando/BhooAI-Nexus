GUIDE

From Empty Project Scaffold a new BhooAI Nexus app from scratch, wire your first routes, and ship a CRUD module — end to end.

This guide takes you from an empty directory to a running app with a custom todos module. It assumes Node.js ≥ 22 and MongoDB ≥ 6 are installed; Redis is optional (the framework degrades gracefully without it).

1. Scaffold with nexus init

The fastest path is the published npm package. From an empty directory:

mkdir my-app
cd my-app
npm init -y
npm install @bhooai/nexus
npx nexus init .
npm install
npm run doctor
npm run dev
Two installs on purpose npm init only writes package.json. Run npx nexus init . after the first install so the CLI binary is on PATH; the second npm install then picks up the generated frontend/admin dependencies.

If you are working inside the monorepo, the equivalent is:

node bin/nexus.js init ./my-app
cd my-app
npm install
npm run dev

2. What init generates

The scaffold copies a real, runnable project tree from packages/nexus-cli/templates/. It is idempotent — existing files are skipped unless you pass --force.

PathPurpose
apps/backend/Node backend (Nexus HTTP server, modules, plugins).
apps/frontend/React + Vite frontend (demo tabs + auth client).
apps/admin/Vite launcher for the admin SPA.
apps/ai-server/Python FastAPI AI server (OpenAI-compatible).
bin/nexus.jsCLI shim (dev, doctor, sync, …).
bin/serve-all.mjsSingle-process launcher used by the Docker image.
nexus.config.tsThe single human-edited config file.
.envProject secrets (gitignored). Loaded automatically.
.gitignoreIgnores node_modules, uploads/, nexus.runtime.json, .env.
uploads/Project-local upload directory (kept via .gitkeep).
Dockerfile + docker.ps1/.sh/.batOne-image build + helper scripts.

The generated backend boots a Nexus HTTP server with the full security stack and serves /health, /csrf-token, /echo, and CSRF-protected /uploads out of the box.

3. The minimal nexus.config.ts

One file holds every host/port and feature toggle. Secrets never live here — they go in .env and are injected via NEXUS_* env vars.

import type { NexusConfig } from '@bhooai/nexus-core';

const config: Partial<NexusConfig> = {
  env: 'development',

  // The HTTP API server the browser/cluster proxy to.
  server: { port: 4000, host: '0.0.0.0', https: false, trustProxy: false, bodyLimit: 12 * 1024 * 1024 },

  // MongoDB host/port/database.
  db: { uri: 'mongodb://localhost:27017/my-app', maxPoolSize: 10, autoIndex: true },

  // Redis (optional — cache, sessions, WS fanout, rate limits).
  redis: { url: 'redis://localhost:6379', keyPrefix: 'myapp:' },

  // Auth: JWT secret comes ONLY from .env (NEXUS_AUTH_JWT_SECRET).
  auth: {
    jwt: { accessTtl: 60 * 15, refreshTtl: 60 * 60 * 24 * 30 },
    cookieName: 'nexus_sid',
    refreshCookieName: 'nexus_rid',
    requireEmailVerification: false,
  },

  // Cluster mesh (off for a single-node app).
  cluster: { enabled: false, failOpenSingleNode: true, lbPort: 8080, nodeAgentPort: 7575, token: '' },
};

export default config;
Precedence Low → high: code defaults < nexus.config.ts < nexus.runtime.json (admin, gitignored) < .env / NEXUS_* < CLI flags. The admin writes only nexus.runtime.json, so your config file stays clean.

4. .env setup

Create a .env at the project root. The framework loads it automatically on boot — do not commit it.

# .env
NEXUS_DB_URI=mongodb://localhost:27017/my-app
NEXUS_REDIS_URL=redis://localhost:6379
NEXUS_AUTH_JWT_SECRET=a-long-random-string-at-least-32-chars
NEXUS_SERVER_BODY_LIMIT=12582912
NEXUS_UPLOADS_DIR=uploads
NEXUS_UPLOADS_PATH=/uploads

# AI provider keys (optional — used by the Python AI server).
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=sk-ant-...
GOOGLE_API_KEY=...
Replace the default secret doctor will flag NEXUS_AUTH_JWT_SECRET if it is still the default. Generate one with, e.g. node -e "console.log(require('crypto').randomBytes(48).toString('hex'))".

6. Add a custom GET route

Open apps/backend/src/main.ts and register a route on the router before NexusServer is constructed:

// apps/backend/src/main.ts
router.get('/hello', (ctx) => {
  ctx.json({ message: 'hello from my-app' });
});

Restart npm run dev and open http://localhost:4000/hello. GET routes are safe methods — they get a fresh CSRF token cookie automatically and do not need an x-csrf-token header.

7. Add a custom POST route (CSRF-protected)

Unsafe methods (POST/PUT/PATCH/DELETE) are CSRF-protected by the security stack. The browser must first GET /csrf-token, then send the returned token in the x-csrf-token header on every POST.

// apps/backend/src/main.ts
router.post('/echo', (ctx) => {
  ctx.json({ received: ctx.body });
});
// Browser
const csrf = await fetch('/csrf-token', { credentials: 'include' }).then(r => r.json());
const r = await fetch('/echo', {
  method: 'POST', credentials: 'include',
  headers: { 'content-type': 'application/json', 'x-csrf-token': csrf.token },
  body: JSON.stringify({ hello: 'world' }),
});
console.log(await r.json()); // { received: { hello: 'world' } }
Origin matters When trustedOrigins is non-empty, every unsafe request must carry an Origin header that exactly matches a trusted origin (including the port) and a matching x-csrf-token. API clients that omit Origin (e.g. Playwright's APIRequestContext) must add it explicitly.

8. Create a custom module

Modules live under apps/backend/src/modules/. The scaffold ships auth/, users/, ai/, payments/, and admin/. Add your own by creating a folder with a routes file and an optional ODM model, then registering it from main.ts.

Convention: each module exports a register<Name>Routes(router, …) function and keeps its model, helpers, and types co-located.

Example: a todos module with CRUD

Folder layout:

apps/backend/src/modules/todos/
  todoModel.ts      # ODM model
  todoRoutes.ts     # registerTodoRoutes(router, guard)

todoModel.ts

import { getModel, schema, types } from '@bhooai/nexus-data';

const TodoSchema = schema({
  title: types.string({ required: true }),
  done: types.boolean({ default: false }),
  owner: types.objectId({ required: true }),
  createdAt: types.date({ default: () => new Date() }),
});

let Todo: ReturnType<typeof getModel>;
export function initTodoModel() {
  Todo = getModel('Todo', TodoSchema);
  return Todo;
}
export function getTodoModel() {
  if (!Todo) throw new Error('Todo model not initialized — call initTodoModel() first');
  return Todo;
}

todoRoutes.ts

import type { Router } from '@bhooai/nexus-core';
import { authToken } from '@bhooai/nexus-auth';
import { initTodoModel, getTodoModel } from './todoModel.js';

export function registerTodoRoutes(router: Router, authService: any, cookieName: string): void {
  initTodoModel();
  const guard = [authToken(authService, { cookieName, allowCookie: true })];

  // List my todos
  router.get('/todos', async (ctx) => {
    const Todo = getTodoModel();
    const userId = (ctx.state.user as { id: string }).id;
    const todos = await Todo.find({ owner: userId }).lean();
    ctx.json({ todos });
  }, guard);

  // Create a todo
  router.post('/todos', async (ctx) => {
    const { title } = (ctx.body ?? {}) as { title?: string };
    if (!title) throw new (ctx.app ?? null)?.ValidationError?.() ?? Error('title required');
    const Todo = getTodoModel();
    const userId = (ctx.state.user as { id: string }).id;
    const [todo] = await Todo.create({ title, owner: userId, done: false });
    ctx.json({ todo });
  }, guard);

  // Toggle done
  router.post('/todos/:id/toggle', async (ctx) => {
    const Todo = getTodoModel();
    const todo = await Todo.findById(ctx.params.id).lean();
    if (!todo) { ctx.json({ error: 'not found' }, 404); return; }
    await Todo.updateOne({ _id: todo._id }, { $set: { done: !todo.done } });
    const updated = await Todo.findById(ctx.params.id).lean();
    ctx.json({ todo: updated });
  }, guard);

  // Delete
  router.delete('/todos/:id', async (ctx) => {
    const Todo = getTodoModel();
    await Todo.deleteOne({ _id: ctx.params.id });
    ctx.json({ ok: true });
  }, guard);
}

Wire it in main.ts

// apps/backend/src/main.ts — after authService is built, before NexusServer
import { registerTodoRoutes } from './modules/todos/todoRoutes.js';
// ...
registerTodoRoutes(router, authService, config.auth.cookieName);

Restart npm run dev. You now have authenticated CRUD for todos at /todos, /todos/:id/toggle, and /todos/:id — all CSRF-protected via the security stack and scoped to the logged-in user via authToken.
