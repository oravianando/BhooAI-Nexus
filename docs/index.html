BhooAI Nexus A Node-based full-stack framework — backend, frontend, AI, and admin in one tree.

Nexus is a source-first platform for building secure, realtime applications without assembling a dozen unrelated runtimes. It combines a Node backend, React frontend, Python AI service, and operator console behind one typed nexus.config.ts, one .env, and one local supervisor.

What it is

Nexus is a monorepo framework: scoped @bhooai/nexus-* packages form the platform, while four runnable services provide the working product surface — a Node backend, a React+Vite frontend, a Python FastAPI AI server, and a React admin console. One supervisor boots the services; one config stack drives them.

Where it matters, everything is built from scratch — no Apollo, no mongoose, no express. The GraphQL federation layer, the ODM, the HTTP server, and the plugin sandbox are all hand-rolled on top of minimal, well-chosen primitives (graphql, mongodb, node:http, worker_threads).

What's inside

Custom HTTP server

Trie router with params/wildcards, middleware pipeline, JSON/urlencoded/multipart parsing, static files — on node:http, no express.

Inbuilt security

Double-submit CSRF (with origin check on the WS upgrade), CORS, security headers, rate limiting — one cohesive unit.

From-scratch ODM

Schemas, hooks, validation, populate, transactions, indexes — on the official mongodb driver, no mongoose.

GraphQL federation

Subgraphs, composition, supergraph SDL, a query planner, entity joins, @provides/@requires — no Apollo.

Realtime + WebRTC

WebSocket rooms, Redis pub/sub fanout, auth on upgrade, WebRTC signaling, and a mediasoup SFU adapter.

Auth & OAuth

JWT access+refresh rotation, session reuse detection, RBAC, Google (PKCE) + Facebook OAuth2, account linking.

Five gateways

Razorpay + PayPal full; PayU, Skrill, Payoneer happy-path; per-provider webhook signature verification.

Email + Certs

SMTP via nodemailer + templates + queue; RSA/ECDSA keypairs, self-signed X.509, and a hand-rolled CSR encoder.

Cache & Ads

Redis cache-aside + rate limiter + pub/sub; a REST-based Google Ads client with a GAQL query builder.

Python AI

FastAPI server (OpenAI + Ollama) behind a single OpenAPI contract; Node proxies/re-emits SSE.

Plugins

Trusted in-process plugins and a sandboxed worker_threads runtime with capability-restricted RPC.

Cluster / Mesh

Node agents on every host, a persisted central registry, a round-robin load balancer, and an RPS/CPU autoscaler with an optional AI advisor.

Admin + CLI

Admin console (config editor → runtime.json, process control, plugins, users, monitoring) + a nexus CLI with a supervisor.

The four terminals

node bin/nexus.js dev starts a custom supervisor that owns four child processes and streams colored, prefixed logs. It also exposes a localhost HTTP control API (start/stop/restart/status/logs) that the admin app consumes — decoupling admin from OS-specific process management.

Configuration model

Use nexus.config.ts for non-secret application behavior and .env for secrets and environment-specific overrides. A generated app owns its own nexus.config.ts; the admin writes only nexus.runtime.json, which is gitignored. The precedence is:

code defaults < nexus.config.ts < nexus.runtime.json < .env / NEXUS_* < CLI flags

Dependency policy

  • Allowed: graphql, mongodb, ws, nodemailer, node-redis, bcrypt/bcryptjs, jose, mediasoup/mediasoup-client.
  • Forbidden: any @apollo/*, mongoose, @graphql-tools/federation, express/fastify/koa.
  • Avoided: concurrently/pm2 (custom supervisor), node-forge (hand-rolled DER for CSRs), werift (use mediasoup).
