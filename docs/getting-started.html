BOOT SEQUENCE

Getting Started Install, configure, verify, and run the Nexus service mesh locally.

Prerequisites

ToolVersionUsed by
Node.js≥ 22backend, frontend, admin, CLI
Python≥ 3.13AI server (optional)
MongoDB≥ 6auth, persistence, GraphQL
Redis≥ 6cache, sessions, WS fanout, rate limits (optional — degrades gracefully)

MongoDB and Redis should be reachable at localhost:27017 and localhost:6379 (override with NEXUS_DB_URI / NEXUS_REDIS_URL).

1. Install

git clone <repo> BhooAI-Nexus
cd BhooAI-Nexus/BhooAI-Nexus/bhooai-nexus
npm install        # installs all npm workspaces

The outer BhooAI-Nexus/ directory is only a container. The package manifest and lockfile are in the nested bhooai-nexus/ workspace root.

The monorepo uses npm workspaces with scoped packages under packages/nexus-*. Inter-package deps use "*" (npm resolves them to the workspace package).

2. Verify the environment

node bin/nexus.js doctor

doctor checks Node/Python versions and MongoDB/Redis reachability. It is advisory: optional services can be unavailable, but the backend still needs MongoDB for auth and persistence. It also flags the default JWT secret, which you should replace.

  ✓ node         v22.20.0
  ✓ python       Python 3.13.7
  ✓ mongodb      localhost:27017 reachable
  ✓ redis        localhost:6379 reachable
  ✗ jwt-secret   still the default — set NEXUS_AUTH_JWT_SECRET

3. Configure

Create one project-root .env file. The framework loads it automatically; do not put secrets in nexus.config.ts or nexus.runtime.json.

# .env
NEXUS_DB_URI=mongodb://localhost:27017/myapp
NEXUS_REDIS_URL=redis://localhost:6379
NEXUS_AUTH_JWT_SECRET=a-long-random-string-at-least-32-chars
NEXUS_PAYMENTS_RAZORPAY_KEY_ID=rzp_test_TO8kiKmXDUC8l8
NEXUS_PAYMENTS_RAZORPAY_KEY_SECRET=cqpmZEC1fbNwvyYC0UhE0P1I
# OpenAI
NEXUS_AI_OPENAI_API_KEY=

# Anthropic Claude
NEXUS_AI_ANTHROPIC_API_KEY=

# Google Gemini
NEXUS_AI_GOOGLE_API_KEY=


# Optional Razorpay example; keys auto-enable the provider.
NEXUS_PAYMENTS_RAZORPAY_KEY_ID=rzp_test_...
NEXUS_PAYMENTS_RAZORPAY_KEY_SECRET=...

App-level settings live in nexus.config.ts. For a generated app, this is the user-defined area; the framework config supplies defaults. Precedence, low → high:

code defaults < framework config < user nexus.config.ts < nexus.runtime.json < .env / NEXUS_* < CLI flags

Uploads use the project-local uploads/ directory. The generated backend accepts multipart/form-data at POST /uploads and serves saved files from /uploads/<generated-name>. The endpoint is CSRF-protected by the default security stack.

4. Run all four terminals

node bin/nexus.js dev

The supervisor boots the backend, frontend, AI server, and admin with colored prefixed logs and handles Ctrl-C gracefully. Visit:

URLWhat
http://localhost:4000/healthBackend liveness
http://localhost:3000Frontend
http://localhost:3001Admin console
http://localhost:8000/healthPython AI server
http://localhost:7474/statusSupervisor control API
Run a single terminal Each terminal is also runnable standalone. From the workspace root use npx tsx apps/backend/src/main.ts; from apps/frontend or apps/admin use npx vite; from apps/ai-server use python main.py. Direct backend startup also loads the project .env.

5. Test

npx vitest run                                      # Node unit/integration tests
pytest                                               # Python AI tests
npx playwright test --config=playwright.config.ts    # cross-service e2e

Integration tests use a real MongoDB (via NEXUS_DB_URI) — there is no embedded Mongo. Frontend client tests are fully mocked (a FakeWebSocket + fetch stub).

Scaffold a new project

node bin/nexus.js init ./my-app
cd my-app
npm install
npm run doctor
npm run dev

init copies a real, runnable project tree from packages/nexus-cli/templates/ — the generated backend boots a Nexus HTTP server with the full security stack and serves /health, /csrf-token, /echo, and /uploads. It is idempotent (skips existing files unless --force).

Use the published npm package

Publish the package from the bhooai-nexus/ workspace root with npm publish. The published package exposes the nexus executable. From an empty directory:

mkdir my-app
cd my-app
npm init -y
 npm install C:\server\BhooAI\BhooAI-Nexus\BhooAI-Nexus\bhooai-nexus
npx nexus init .
npm install
npm run doctor
npm run dev

Run npx nexus init . after the first npm install; npm init only creates the project package.json. The second install picks up generated frontend/admin dependencies. The generated project owns the doctor and dev scripts.

Frontend styling

Scaffolded frontends ship with Tailwind CSS and a framework-owned PostCSS preset (@bhooai/nexus-postcss). The postcss.config.js loads the entire plugin chain — Tailwind, nesting, autoprefixing, minification — with one line:

import { createPreset } from '@bhooai/nexus-postcss';
export default createPreset();

A design-token stylesheet (theme.css) provides 22 CSS custom properties (--nexus-bg, --nexus-ink, --nexus-accent, etc.) for a consistent dark theme baseline. Import it at the top of your index.css:

@import '@bhooai/nexus-postcss/theme.css';
@tailwind base;
@tailwind components;
@tailwind utilities;

See the Frontend Styling guide and the PostCSS API reference for full documentation.
