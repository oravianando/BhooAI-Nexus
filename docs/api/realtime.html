@bhooai/nexus-realtime Realtime API WebSocket rooms, Redis fanout, WebRTC signaling, mediasoup SFU.

The realtime package. A ws-based WebSocket server with rooms, direct peer signaling, an optional mediasoup SFU, and a pluggable pub/sub adapter for cross-instance fanout. Mounted via noServer upgrade handling so it shares the HTTP server's port.

Types — wire protocol

The JSON text frames exchanged over the socket are typed by ClientMessage (client → server) and ServerMessage (server → client). mediasoup signaling is relayed as a media frame whose action is a MediaAction.

ClientMessage

type ClientMessage =
  | { type: 'join'; room: string }
  | { type: 'leave'; room: string }
  | { type: 'offer'; to: string; sdp: string; room?: string }
  | { type: 'answer'; to: string; sdp: string; room?: string }
  | { type: 'candidate'; to: string; candidate: unknown; room?: string }
  | { type: 'broadcast'; room: string; event: string; data?: unknown }
  | { type: 'ping' }
  | { type: 'media'; action: MediaAction; payload: Record<string, unknown> };
typePayloadEffect
ping—Server replies pong (keepalive).
join{ room }Join a room; server replies joined with the other local members.
leave{ room }Leave a room; server replies left.
offer / answer / candidate{ to, sdp } | { to, candidate }WebRTC signaling relayed to the target peer — direct if same-instance, else published to the conn:<to> pub/sub channel.
broadcast{ room, event, data? }Fan out an event to every other peer in the room (cross-instance via room:<room>).
media{ action, payload }mediasoup SFU request (request/response; server replies with a media frame of the same action).

Pub/sub adapters

The pub/sub adapter is the cross-instance fanout backbone. RealtimeServer publishes room events to a room:<room> channel and direct peer messages to a conn:<id> channel; every instance's subscriber delivers to its local members. This gives exactly-once delivery per instance without the originator also sending locally.

PubSubAdapter (interface)

interface PubSubAdapter {
  publish(channel: string, message: Buffer | string): void;
  subscribe(channel: string, handler: (message: Buffer | string) => void): Promise<void> | void;
  unsubscribe(channel: string, handler: (message: Buffer | string) => void): Promise<void> | void;
}

The structural interface every adapter implements. publish is fire-and-forget; subscribe / unsubscribe may be sync or async. Implement this to plug in a different broker (NATS, Redis Streams, etc.).

MemoryPubSubAdapter (class — the default)

class MemoryPubSubAdapter implements PubSubAdapter {
  constructor();
  publish(channel: string, message: Buffer | string): void;
  subscribe(channel: string, handler: (message: Buffer | string) => void): void;
  unsubscribe(channel: string, handler: (message: Buffer | string) => void): void;
}

Single-process EventEmitter-backed adapter. This is the default — RealtimeServer uses new MemoryPubSubAdapter() when RealtimeServerOptions.adapter is omitted. Fine for tests and single-node deployments; use RedisPubSubAdapter for horizontal scaling. The emitter is constructed with setMaxListeners(0) to allow many room subscribers.

RedisLike (interface)

interface RedisLike {
  publish(channel: string, message: string): Promise<number>;
  subscribe(...channels: string[]): Promise<number>;
  unsubscribe(...channels: string[]): Promise<number>;
  on(event: 'message', listener: (channel: string, message: string) => unknown): unknown;
  off(event: 'message', listener: (channel: string, message: string) => unknown): unknown;
}

The minimal Redis client interface RedisPubSubAdapter depends on — structurally compatible with node-redis (createClient()). Kept structural so the realtime package does not hard-depend on a Redis client at import time; @bhooai/nexus-cache supplies a configured client.

RedisPubSubAdapter (class)

class RedisPubSubAdapter implements PubSubAdapter {
  constructor(client: RedisLike);
  publish(channel: string, message: Buffer | string): void;
  subscribe(channel: string, handler: (message: Buffer | string) => void): Promise<void>;
  unsubscribe(channel: string, handler: (message: Buffer | string) => void): Promise<void>;
}

Redis-backed pub/sub for multi-instance room broadcast. Uses one configured Redis client in subscribe mode; messages are JSON strings. On construction it registers a single 'message' listener that routes incoming Redis messages to the per-channel handler sets it tracks internally. subscribe calls client.subscribe(channel) only on the first handler for a channel; unsubscribe calls client.unsubscribe(channel) when the last handler for a channel is removed.

import { createClient } from 'redis';
import { RedisPubSubAdapter } from '@bhooai/nexus-realtime';

const client = createClient({ url: config.redis.url });
await client.connect();
const adapter = new RedisPubSubAdapter(client);

RealtimeServer

class RealtimeServer {
  constructor(opts: RealtimeServerOptions);
  broadcast(room: string, event: string, data?: unknown): void;
  get connectionCount(): number;
  close(): Promise<void>;
}

WebSocket realtime server. The constructor attaches a noServer WebSocketServer and registers an 'upgrade' listener on opts.httpServer. The upgrade handler runs the CSRF/origin check, authenticates the access token, then completes the WS handshake and registers a Connection.

Client messages are dispatched by type: join/leave manage room membership; offer/answer/candidate relay WebRTC signaling (direct when same-instance, else published to conn:<to>); broadcast publishes to room:<room>; media delegates to the MediasoupAdapter. On close, the connection leaves all its rooms and mediasoup.cleanup(conn) is called.

MemberDescription
constructor(opts)Attach to opts.httpServer. Uses opts.adapter ?? new MemoryPubSubAdapter().
broadcast(room, event, data?)Publish a server-originated app event to every connection in room (from: 'server').
get connectionCountNumber of live connections (test/monitoring helper).
close()Close every connection with 1001 'server shutting down' and close the WS server. Returns a resolved promise.
 
import { RealtimeServer, RedisPubSubAdapter, MediasoupAdapter } from '@bhooai/nexus-realtime';

const realtime = new RealtimeServer({
  httpServer: server.httpServer,
  path: '/ws',                                       // default '/ws'
  authService,                                      // verify ?token= on upgrade
  csrfOptions: config.ws.requireCsrf ? { trustedOrigins } : undefined,
  adapter: new RedisPubSubAdapter(redisClient),          // default: MemoryPubSubAdapter
  mediasoup: new MediasoupAdapter({ announceIp: config.webrtc.announceIp }), // optional
  requireAuth: true,                                  // default true when authService provided
});
realtime.broadcast('lobby', 'announce', { text: 'hi' });
console.log(realtime.connectionCount);
await realtime.close();
Design note deliverRoom skips the originator, so peers never receive their own peer-joined/peer-left/broadcast echo. Signaling (offer/answer/candidate) is direct when same-instance, else published to a conn:<to> channel for cross-instance delivery.

MediasoupAdapter

Wraps the mediasoup SFU. Lazily imports the native mediasoup package (an optional dependency) so the realtime package loads even when mediasoup is not installed; media actions then return { code: 'NO_SFU' } from the server. One worker is created per adapter; one router per room (default Opus audio + VP8 video codec set). Each connection gets a send and a recv WebRtcTransport; producers/consumers are tracked per connection.
