@bhooai/nexus-ai-client AI Client API Node client for the Python AI server — chat, streaming, embeddings, retries.

The browser never calls Python directly — the Node backend proxies/re-emits SSE. This client is what the backend uses to talk to the FastAPI AI server. It is OpenAI-compatible: the request/response shapes mirror the OpenAI Chat Completions and Embeddings APIs. The wire contract is defined in contracts/ai-openapi.yaml.

Usage

import { AiClient } from '@bhooai/nexus-ai-client';

const ai = new AiClient({ serverUrl: config.ai.serverUrl, timeoutMs: 60_000 });

// non-streaming — model is REQUIRED
const reply = await ai.chat({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'hi' }],
  provider: 'ollama',
});

// streaming — async generator over SSE chunks; delta lives on choices[i].delta
for await (const chunk of ai.chatStream({
  model: 'gpt-4o-mini',
  messages: [{ role: 'user', content: 'tell me a joke' }],
})) {
  process.stdout.write(chunk.choices[0]?.delta?.content ?? '');
}

// embeddings — model is REQUIRED
const vec = await ai.embeddings({ model: 'text-embedding-3-small', input: 'hello world' });

const models = await ai.listModels();          // all providers
const ollamaModels = await ai.listModels('ollama'); // one provider
Behavior Every method (chat, chatStream, embeddings, listModels) routes through the private request<T> helper, which applies an AbortController timeout and exponential-backoff retries with deterministic jitter. Retryable: network failures (no status), 5xx, and 429. Non-retryable: other 4xx. The client forwards the provider field to the server (which strips it before calling upstream).

AiClient

class AiClient {
  constructor(opts: AiClientOptions);
  chat(req: ChatCompletionRequest): Promise<ChatCompletionResponse>;
  chatStream(req: ChatCompletionRequest): AsyncGenerator<ChatCompletionChunk, void, unknown>;
  embeddings(req: EmbeddingRequest): Promise<EmbeddingResponse>;
  listModels(provider?: string): Promise<ModelsResponse>;
}

Node client for the BhooAI Nexus AI server (Python FastAPI). OpenAI-compatible. Supports non-streaming and streaming chat completions, embeddings, and model listing, with timeout (AbortController) and exponential-backoff retries on transient failures (network errors, 5xx, 429).

The constructor strips trailing slashes from serverUrl. Methods POST JSON to /chat/completions, /embeddings, and GET /models on the AI server. chat forces stream: false; chatStream forces stream: true and accepts text/event-stream.

chat(req)

async chat(req: ChatCompletionRequest): Promise<ChatCompletionResponse>

Non-streaming chat completion. Sends { ...req, stream: false } to POST /chat/completions and returns the parsed ChatCompletionResponse.

chatStream(req)

async function* chatStream(req: ChatCompletionRequest): AsyncGenerator<ChatCompletionChunk, void, unknown>

Streaming chat completion — an async generator that yields ChatCompletionChunk values until the stream ends. Sends { ...req, stream: true } with accept: text/event-stream, then pipes the response body through parseSseStream. Throws AiError if the response has no body. The incremental text lives at chunk.choices[0]?.delta?.content — there is no top-level delta field on ChatCompletionChunk.

embeddings(req)

async embeddings(req: EmbeddingRequest): Promise<EmbeddingResponse>

Create embeddings for one or more inputs. POST /embeddings.

listModels(provider?)

async listModels(provider?: string): Promise<ModelsResponse>

List available models, optionally filtered to a single provider (appends ?provider=<encoded>). GET /models.

AiClientOptions

FieldTypeDefaultDescription
serverUrlstring—Required. AI server base URL, e.g. http://localhost:8000. Trailing slashes are stripped.
timeoutMs?number60000Per-request timeout in ms; enforced via AbortController (abort → AiError('AI request timed out')).
maxRetries?number2Max retry attempts on transient errors (network failures, 5xx, 429).
retryDelayMs?number500Base delay for exponential backoff in ms. Delay = retryDelayMs * 2^attempt + attempt (deterministic jitter, no Math.random).
authToken?string—Optional Bearer token sent as authorization: Bearer <token> to the AI server.
Retry & backoff request<T> loops attempt = 0..maxRetries. On a non-OK HTTP response it builds an AiError from the JSON error body (body.error.message / body.error.code). On an abort/network throw it wraps the message. If isRetryable(err) and attempts remain, it waits retryDelayMs * 2^attempt + attempt ms (deterministic jitter folded from the attempt index) and retries; otherwise it throws. After the loop, the last error is rethrown (or a generic AiError('AI request failed')).

parseSseStream(stream)

async function* parseSseStream(stream: ReadableStream<Uint8Array>): AsyncGenerator<any, void, unknown>

Minimal SSE parser for the streaming chat endpoint. Reads a web ReadableStream<Uint8Array>, buffers bytes, splits events on blank lines (\n\n), collects data: lines per event (concatenated with \n), and yields the JSON.parsed payload of each event. Stops immediately when a payload is [DONE]. Malformed JSON is skipped. After the stream ends, any trailing event without a blank-line terminator is flushed. The reader's lock is released in a finally block.

import { parseSseStream } from '@bhooai/nexus-ai-client';

const res = await fetch('http://localhost:8000/chat/completions', {
  method: 'POST',
  headers: { 'content-type': 'application/json', accept: 'text/event-stream' },
  body: JSON.stringify({ model: 'gpt-4o-mini', messages: [...], stream: true }),
});
for await (const chunk of parseSseStream(res.body!)) {
  console.log(chunk.choices[0]?.delta?.content ?? '');
}

Errors — AiError & isRetryable

class AiError extends Error {
  readonly status?: number;
  readonly code?: string;
  constructor(message: string, opts: { status?: number; code?: string } = {});
}

function isRetryable(err: unknown): boolean;

AiError is the error class thrown by AiClient. name is set to 'AiError'; status is the upstream HTTP status (absent for network-level failures), code is the upstream error code if present.

FieldTypeDescription
messagestringError message (from upstream body.error.message, or 'AI server <status>', or 'AI request timed out' / the network error message).
status?numberUpstream HTTP status. undefined for network-level failures (abort, DNS, connection refused).
code?stringUpstream error code from body.error.code, if the error body was JSON.

isRetryable(err) classifies whether an error is transient and worth retrying:

  • An AiError with status === undefined → true (network-level failure).
  • An AiError with status >= 500 or status === 429 → true.
  • Any other AiError (other 4xx) → false.
  • A non-AiError value → true (treated as an unknown/transient failure).

Backend proxy

The backend's registerAiRoutes mounts POST /ai/chat/completions (stream → writeHead text/event-stream + re-emit data: {chunk}\n\n + data: [DONE]), POST /ai/embeddings, and GET /ai/models. CSRF applies to the POSTs.
