@bhooai/nexus-postcss PostCSS Preset API Opinionated PostCSS pipeline — Tailwind, nesting, future CSS, autoprefixing, and minification in one curated preset.

A single, framework-owned PostCSS preset that every Nexus frontend and admin app consumes. Scaffolded projects get it automatically via nexus init; existing apps add it with one line in postcss.config.js.

Why a preset? Nexus follows a "from-scratch where it matters" philosophy. The preset packages the entire CSS build chain — Tailwind, nesting, autoprefixing, minification — behind one versioned, curated entry point so scaffolded projects don't hand-maintain a plugin list.

Plugin chain (in order)

#PluginWhat it does
1postcss-importResolves @import statements — enables @import '@bhooai/nexus-postcss/theme.css'
2postcss-nestedNative CSS nesting (& .child { }) before Tailwind processes @apply
3tailwindcssInjects @tailwind base/components/utilities + scans content paths for utility classes
4postcss-preset-envFuture CSS features today (stage 2 by default) — color-mix(), @custom-media, etc.
5autoprefixerVendor prefixes based on browserslist
6cssnanoMinification — only when NODE_ENV=production or minify:true
Plugin resolution All plugins are imported and instantiated inside the preset package, not resolved from the consumer's node_modules. This means scaffolded projects don't need to install postcss-import, postcss-nested, etc. directly — they're transitive deps of @bhooai/nexus-postcss.

createPreset(options)

Returns { plugins: PostCSSPlugin[] } — an array of instantiated PostCSS plugins ready for postcss.config.js.

Usage

Default (scaffolded projects)

// postcss.config.js
import { createPreset } from '@bhooai/nexus-postcss';

export default createPreset();

With framework admin content scanning

// postcss.config.js (admin app)
import { createPreset } from '@bhooai/nexus-postcss';

export default createPreset({
  extraContent: ['../../packages/nexus-admin/src/**/*.{ts,tsx}'],
});

With Tailwind theme extensions

export default createPreset({
  theme: {
    colors: {
      brand: '#67e8f9',
    },
  },
  tailwindPlugins: [require('@tailwindcss/forms')],
});

Disabling specific plugins

export default createPreset({
  import: false,
  nested: false,
  presetEnv: false,
  autoprefixer: false,
});

Always minify (even in dev)

export default createPreset({ minify: true });

Appending custom PostCSS plugins

export default createPreset({
  plugins: [
    ['my-postcss-plugin', { foo: 1 }],
    'another-plugin',
  ],
});

Tailwind config

Each app keeps its own tailwind.config.js. The preset only injects content paths and the plugin chain — theme extensions and Tailwind plugins stay in your tailwind.config.js.

// tailwind.config.js (default scaffolded)
export default {
  content: ['./index.html', './src/**/*.{ts,tsx}'],
  theme: { extend: {} },
  plugins: [],
};

theme.css — Design tokens

Import the framework-wide design tokens with a single @import at the top of your index.css:

/* src/index.css */
@import '@bhooai/nexus-postcss/theme.css';

@tailwind base;
@tailwind components;
@tailwind utilities;

Retheming

Override any token in your own :root block:

/* src/index.css */
@import '@bhooai/nexus-postcss/theme.css';

:root {
  --nexus-accent: #ff6b6b;  /* retheme the accent color */
  --nexus-bg: #1a1a2e;     /* change the background */
}

Example CSS classes

The scaffolded index.css ships with three example classes built from Nexus tokens:

/* Frosted-glass card */
.nexus-card {
  background: var(--nexus-surface);
  border: 1px solid var(--nexus-border);
  border-radius: var(--nexus-radius);
  color: var(--nexus-ink);
  padding: 1.5rem;
  backdrop-filter: blur(20px);
}

/* Ambient mesh background */
.nexus-mesh-bg {
  background: var(--nexus-mesh), var(--nexus-bg);
  background-attachment: fixed;
  min-height: 100vh;
}

/* Accent-colored link */
.nexus-link {
  color: var(--nexus-accent);
  text-decoration: none;
}
