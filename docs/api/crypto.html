@bhooai/nexus-crypto Crypto API Keypairs, self-signed X.509, PKCS#10 CSRs (hand-rolled DER), and HTTPS/mTLS helpers.

The crypto package. Generates RSA/EC keypairs, builds self-signed X.509 v3 certificates and PKCS#10 Certificate Signing Requests with a hand-rolled ASN.1/DER encoder (no node-forge), and provides small HTTPS/mTLS helpers. Everything signs with SHA-256 via node:crypto.

Why hand-rolled? node:crypto can create keypairs and parse certificates, but it cannot create CSRs. Rather than pull in node-forge, Nexus ships a minimal ASN.1/DER encoder (~260 lines). The CSR includes challengePassword + extensionRequest attributes and PEM-encodes with the standard CERTIFICATE REQUEST label. Certificates (not CSRs) are parseable by Node's X509Certificate; the private key PEM round-trips through createPrivateKey.

Usage

import { generateKeyPair, createSelfSignedCertificate, createCsr } from '@bhooai/nexus-crypto';

const kp = generateKeyPair('rsa', { modulusLength: 2048 });
const cert = createSelfSignedCertificate({ keyPair: kp, commonName: 'localhost' });
const csr = createCsr({
  keyPair: kp,
  commonName: 'localhost',
  organization: 'BhooAI',
  country: 'IN',
  challengePassword: 'verify-me',
});

cert.pem;       // PEM certificate (-----BEGIN CERTIFICATE-----)
kp.pem.private; // PKCS#8 private key PEM
kp.pem.public;  // SPKI public key PEM
csr.pem;        // PEM CSR (-----BEGIN CERTIFICATE REQUEST-----)

The backend exposes certificate/CSR creation at POST /certs/self-signed (CSRF-protected), with optional { csr: true } to also return a CSR.

Keypairs

generateKeyPair(type, opts?)

function generateKeyPair(
  type: 'rsa' | 'ec',
  opts?: KeyPairOptions,
): KeyPairResult

Generate an RSA or EC keypair via crypto.generateKeyPairSync. Returns DER buffers (SPKI public, PKCS#8 private) plus PEM strings. RSA defaults to 2048-bit; EC defaults to prime256v1 (P-256). modulusLength applies only to 'rsa'; namedCurve applies only to 'ec'.

const rsa = generateKeyPair('rsa', { modulusLength: 4096 });
const ec  = generateKeyPair('ec',  { namedCurve: 'prime256v1' });

rsa.publicKey;  // Buffer — SPKI DER
rsa.privateKey; // Buffer — PKCS#8 DER
rsa.pem.public; rsa.pem.private;

X.509 self-signed certificates

createSelfSignedCertificate(opts)

function createSelfSignedCertificate(opts: X509Options): X509Result

Build a self-signed X.509 v3 certificate by hand: assembles a TBSCertificate DER, signs it with the private key (SHA-256), and wraps it as SEQUENCE { tbs, sigAlgId, signature }. Detects RSA vs EC from the key and picks the matching algorithm identifier. No extensions are added (a v3 cert with no extensions is still valid DER). The resulting cert buffer is parseable by Node's X509Certificate.

const kp = generateKeyPair('rsa');
const { cert, pem } = createSelfSignedCertificate({
  keyPair: kp,
  commonName: 'localhost',
  organization: 'BhooAI',
  country: 'IN',
  notBefore: new Date(),
  notAfter: new Date(Date.now() + 90 * 24 * 60 * 60 * 1000),
  serial: 0x1,
});

import { X509Certificate } from 'node:crypto';
new X509Certificate(cert).subjectAltName; // parseable

PKCS#10 Certificate Signing Requests

createCsr(opts)

function createCsr(opts: CsrOptions): CsrResult

Create a PKCS#10 CSR by hand: assembles CertificationRequestInfo DER, signs it with the private key (SHA-256), and wraps it as SEQUENCE { cri, sigAlgId, signature }. Supports an optional challengePassword attribute and an extensionRequest attribute carrying arbitrary extensions (e.g. subjectAltName). PEM label is CERTIFICATE REQUEST.

const { csr, pem } = createCsr({
  keyPair: kp,
  commonName: 'localhost',
  organization: 'BhooAI',
  country: 'IN',
  challengePassword: 'prove-ownership',
  extensions: [
    { type: '2.5.29.17', value: Buffer.from('...DER...') },        // subjectAltName
    { type: '2.5.29.15', value: Buffer.from('...DER...'), critical: true },
  ],
});
Extensions are raw DER Each extension's value is embedded verbatim as an OCTET_STRING. The caller is responsible for encoding the extension value DER (e.g. a GeneralNames sequence for subjectAltName). createCsr only wraps it in the Extension + extensionRequest structures.

DER / ASN.1 encoder

A minimal hand-rolled DER encoder (~260 lines, no external deps). Works in arrays of byte values (number[]) and flattens to a Buffer at the end via toBuffer. Sufficient to encode X.509 TBSCertificates and PKCS#10 CSRs.
