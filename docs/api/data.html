@bhooai/nexus-data Data / ODM API A from-scratch ODM on the official mongodb driver (no mongoose).

A self-contained ODM layer: schemas with defaults, validation, refs/population, hooks, indexes, a fluent Query builder, and a thin connection abstraction. Everything builds on mongodb directly — there is no mongoose dependency.

Top-level helpers

connect(uri, options?)

function connect(uri: string, options: ConnectOptions = {}): Connection

Open a MongoClient and store it as the module-level default connection. Returns the Connection. This is the connection used by getConnection() and model(). It is not registered on the ConnectionManager — getConnection() returns the same object set here, not connectionManager.get('default').

import { connect } from '@bhooai/nexus-data';
const conn = connect('mongodb://localhost:27017/nexus', { autoIndex: true });
Single vs. multi-connection connect() sets one default connection. For multiple databases, use the connectionManager separately — it is independent of the default and is what the projects module uses.

getConnection()

function getConnection(): Connection

Return the default Connection set by connect(). Throws 'Not connected — call connect(uri) first.' if connect() was never called.

model<T>(name, schema, options?)

function model<T extends DocumentInstance>(
  name: string, schema: NexusSchema, options?: { collection?: string },
): Model<T>

Register (or fetch the cached) model on the default connection. Equivalent to getConnection().model(name, schema, options). Re-calling with the same name returns the existing model (schema/options are ignored).

const Post = model<PostDoc>('Post', postSchema, { collection: 'posts' });

transaction(fn)

async function transaction<T>(fn: (session: ClientSession) => Promise<T>): Promise<T>

Start a session on the default connection and run fn inside session.withTransaction(...). The session is always ended in finally.

await transaction(async (session) => {
  await Post.updateOne({ _id }, { $inc: { views: 1 } }, { session });
  await Audit.create([{ at: new Date() }], { session });   // pass session to driver calls
});

ObjectId / Decimal128

import { ObjectId, Decimal128 } from '@bhooai/nexus-data'; // re-exported from mongodb

Re-exports of the mongodb driver BSON types. Use ObjectId for _id construction/casting and Decimal128 for the Decimal128 schema type.

Connection class

class Connection {
  client: MongoClient;
  dbPromise: Promise<Db>;
  models = new Map<string, Model<any>>();
  autoIndex: boolean;
  constructor(uri: string, options: ConnectOptions = {});
  get db(): Promise<Db>;
  model<T extends DocumentInstance>(name: string, schema: NexusSchema, options?: { collection?: string }): Model<T>;
  startSession(): Promise<ClientSession>;
  close(): Promise<void>;
}

Wraps a MongoClient and lazily exposes a Db. The constructor connects immediately — this.db is a promise that resolves once the client handshake completes. Models are registered per connection and indexed by name.

const conn = new Connection(uri, { name: 'myapp', autoIndex: true });
const db = await conn.db;
const User = conn.model<UserDoc>('User', userSchema); // collection name defaults to 'users'
const session = await conn.startSession();
await conn.close();

Constructor

new Connection(uri: string, options: ConnectOptions = {})

Creates the MongoClient and kicks off client.connect(). ODM-only options (name, autoIndex) are stripped before the rest is passed to the driver.

ConnectOptions

Extends MongoClientOptions with two ODM-only fields:

FieldTypeDefaultDescription
name?string— (from URI)Database name override (otherwise taken from the URI).
autoIndex?booleantrueAuto-create schema-declared indexes when a model is registered.

db (getter)

get db(): Promise<Db>

The Promise<Db> for the connected database. Awaits the driver handshake and resolves with client.db(name).

model(name, schema, options?)

model<T extends DocumentInstance>(name: string, schema: NexusSchema, options?: { collection?: string }): Model<T>

Register a model on this connection. If name is already registered, the existing model is returned (schema and options are ignored). The collection name is resolved in order: options.collection → schema.options.collection → name.toLowerCase() + 's'. When autoIndex is true, schema indexes are created in the background (fire-and-forget).

startSession()

async startSession(): Promise<ClientSession>

Await the DB handshake, then return client.startSession(). Used by transaction().

close()

async close(): Promise<void>

Close the underlying MongoClient.

ConnectionManager class & connectionManager

class ConnectionManager {
  private connections = new Map<string, Connection>();
  connect(name: string, uri: string, options: ConnectOptions = {}): Connection;
  get(name = 'default'): Connection;
  has(name: string): boolean;
  async closeAll(): Promise<void>;
}
export const connectionManager = new ConnectionManager();

A process-wide registry for multiple named connections (e.g. a primary app DB plus an analytics DB). The exported connectionManager singleton is the instance used by the projects module.

Independent of the default connection connect() / getConnection() / model() use a module-level defaultConnection variable — they do not register or read from connectionManager. The two APIs are separate; reach for the manager only when you need more than one database in the same process. 
import { connectionManager } from '@bhooai/nexus-data';
const analytics = connectionManager.connect('analytics', 'mongodb://localhost:27017/analytics');
const same = connectionManager.get('analytics');   // cached — same object
connectionManager.has('analytics');                 // true
await connectionManager.closeAll();                   // close every managed connection

Schema (NexusSchema)

class NexusSchema<T = unknown> {
  compiledPaths = new Map<string, CompiledField>();
  indexes: IndexSpec[] = [];
  options: SchemaOptions;
  virtuals = new Map<string, { get?: () => unknown; set?: (v: unknown) => void }>();
  preHooks  = new Map<string, Array<(ctx: unknown) => unknown | Promise<unknown>>>();
  postHooks = new Map<string, Array<(ctx: unknown) => unknown | Promise<unknown>>>();
  methods:  Record<string, (...a: unknown[]) => unknown> = {};
  statics:  Record<string, (...a: unknown[]) => unknown> = {};
  constructor(definition: SchemaDefinition = {}, options: SchemaOptions = {});
  define(path: string, def: FieldDefinition): void;
  virtual(path: string, opts?: { get?: () => unknown; set?: (v: unknown) => void }): void;
  pre(event: string, fn: (ctx: unknown) => unknown | Promise<unknown>): void;
  post(event: string, fn: (ctx: unknown) => unknown | Promise<unknown>): void;
  method(name: string, fn: (...a: unknown[]) => unknown): void;
  staticMethod(name: string, fn: (...a: unknown[]) => unknown): void;
  applyDefaults(doc: Record<string, unknown>): Record<string, unknown>;
  validate(doc: Record<string, unknown>): void;
}

The ODM's schema. Compiles a SchemaDefinition into compiledPaths (validated/coerced on save and query), collects indexes, and stores hooks, virtuals, and instance/static methods. Exported as Schema (an alias of NexusSchema).

import { Schema } from '@bhooai/nexus-data';

const postSchema = new Schema({
  title:  { type: String, required: true },
  views:  { type: Number, default: 0, min: 0, immutable: true },
  author: { type: 'ObjectId', ref: 'User', required: true },
}, { timestamps: true, collection: 'posts' });

postSchema.pre('save', function () { if (this.isModified('title')) this.slug = slugify(this.title); });
postSchema.virtual('preview', { get() { return this.body?.slice(0, 100); } });

Constructor

new NexusSchema(definition: SchemaDefinition = {}, options: SchemaOptions = {})

Compiles each field definition via define(path, normalizeField(raw)). Defaults options to { timestamps: false, versionKey: '__v', strict: true }. When options.timestamps is set, auto-defines createdAt/updatedAt Date fields (default field names) unless they already exist. A bare value (e.g. String) is shorthand for { type: String }.

define(path, def)

define(path: string, def: FieldDefinition): void

Compile a single field into compiledPaths, and push derived index specs into indexes. unique produces a unique index (with sparse honored); index produces a plain index (or accepts an options object); expires produces a TTL index (expireAfterSeconds).

virtual(path, opts?)

virtual(path: string, opts: { get?: () => unknown; set?: (v: unknown) => void } = {}): void

Register a virtual property. The getter is bound to the document instance when invoked by toObject(), so it can read sibling fields via this. Virtuals are not persisted; getters that throw are swallowed during serialization.

pre / post(event, fn)

pre(event: string, fn: (ctx: unknown) => unknown | Promise<unknown>): void
post(event: string, fn: (ctx: unknown) => unknown | Promise<unknown>): void

Append a pre/post hook for an event. The function receives a context bound as this and the first argument. Recognized events:

EventWhenContext shape
'save'DocumentInstance.save()this = the document
'validate'DocumentInstance.validate()this = the document
'remove'DocumentInstance.remove()this = the document
'find' / 'findOne'Query.exec() (pre only mutates filter){ filter, model, op }
'updateOne'Model.updateOne(){ filter, update, model }
'deleteMany'Model.deleteMany(){ filter, model }
 
Post.pre('save', function () { if (this.isModified('title')) this.slug = slugify(this.title); });
Post.post('save', (doc) => log.info('saved', { id: doc._id }));

method / staticMethod(name, fn)

method(name: string, fn: (...a: unknown[]) => unknown): void
staticMethod(name: string, fn: (...a: unknown[]) => unknown): void

Attach an instance method (method) or a static method (staticMethod). Statics are bound to the Model instance in its constructor and called as Model.myStatic(...).

applyDefaults(doc)

applyDefaults(doc: Record<string, unknown>): Record<string, unknown>

For every compiled field with a default, set doc[path] when it is undefined. Function defaults are invoked. Mutates and returns doc.

validate(doc)

validate(doc: Record<string, unknown>): void

Coerce, transform, and validate every field. Throws a ValidationError (the core NexusError subclass, re-exported here) with the list of field errors as details when any check fails. Honors strict: true strips unknown keys, 'throw' adds them as errors, false leaves them alone. Coercion is per-type via coerce.

Schema types

SchemaTypeToken

type SchemaTypeToken =
  | 'String' | 'Number' | 'Boolean' | 'Date'
  | 'Buffer' | 'ObjectId' | 'Decimal128' | 'Mixed'
  | 'Array' | 'Map';

The primitive type tokens the ODM understands. Used as the compiled token on a CompiledField, and accepted directly as a FieldDefinition.type string.

typeOf(ctor)

function typeOf(ctor: unknown): SchemaTypeToken

Map a JS constructor to its SchemaTypeToken. Object → 'Mixed', Array → 'Array', Map → 'Map', Binary → 'Buffer', unknown constructors → 'Mixed'. Used by schema compilation when a constructor is passed as type.

coerce(token, value)

function coerce(token: SchemaTypeToken, value: unknown): unknown

Coerce a value to the target type, throwing TypeError on impossible coercion. null/undefined pass through. Notable rules:

  • String — stringifies numbers/booleans/Date; ObjectId → hex string.
  • Number — Number(value); throws if NaN.
  • Boolean — accepts true/false, 1/0, and the strings 'true'/'false'.
  • Date — new Date(value); throws if invalid.
  • Buffer — accepts a Buffer or a UTF-8 string.
  • ObjectId — accepts an ObjectId or a 24-char hex string.
  • Decimal128 — accepts a Decimal128, a string, or a number.
  • Mixed / Array / Map — returned as-is.

Schema definition interfaces

FieldDefinition

A field's compiled options. A bare constructor (e.g. String) is shorthand for { type: String }. All fields:

FieldTypeDescription
typeunknownA JS constructor, an array [Constructor], a nested Schema, or a SchemaTypeToken string. Required.
requiredboolean | (() => boolean)Field must be present. Function form is evaluated at validate time.
defaultunknown | (() => unknown)Applied by applyDefaults when the field is undefined. Function form is invoked.
enumunknown[]Allowed values; coerced value must be in the list.
minnumberMin bound for Number fields.
maxnumberMax bound for Number fields.
matchRegExpFormat test for String fields.

refstringModel name for population (static reference).
refPathstringName of the field whose value is the model name (dynamic reference).
selectbooleanWhen false, excluded from query results by default (projection). Default true.
immutablebooleanCannot be written after the initial insert. save() skips it on update.
expiresnumberCreates a TTL index with expireAfterSeconds = this value.
indexboolean | Record<string, unknown>Creates an index. Object form is passed as the index options.

new Schema({
  email:    { type: String, required: true, unique: true, sparse: false, match: /@/, transform: (v) => v.toLowerCase() },
  author:   { type: 'ObjectId', ref: 'User', required: true },
  kind:     { type: 'ObjectId', refPath: 'kindType' }, // dynamic ref
  tags:     { type: [String], default: [] },
  views:    { type: Number, default: 0, min: 0, max: 1000000, immutable: true },
  status:   { type: String, enum: ['draft', 'live'], default: 'draft', index: true },
  bio:      { type: String, select: false }, // excluded by default
  token:    { type: String, expires: 3600 }, // TTL index
  name:     { type: String, validate: { validator: (v) => v.length > 1, message: 'name too short' } },
}, { timestamps: true, collection: 'posts', strict: true });

DocumentInstance class

class DocumentInstance {
  _doc: Record<string, unknown> = {};
  _schema: NexusSchema;
  _model: Model<this>;
  _isNew = true;
  _modified = new Set<string>();
  constructor(schema, model, data, isNew = true);
  isModified(path?): boolean;
  toObject(): Record<string, unknown>;
  toJSON(): Record<string, unknown>;
  async validate(): Promise<void>;
  async populate(path): Promise<this>;
  async save(): Promise<this>;
  async remove(): Promise<void>;
}

A hydrated document wrapping a plain object. Field access is proxied to _doc, so doc.email reads/writes the stored value and writes mark the path as modified. New documents (_isNew) start with every initial field marked modified so pre('save') hooks see them as changed. Build instances via Model.create() (new) or Model.hydrate() (persisted); new DocumentInstance(...) is also possible but the model methods are the intended API.

const p = new Post({ title: 'Hi', author: uid });
await p.save();          // runs pre('save'); inserts (new) or updates (modified only)
await p.populate('author'); // single arg — field selection is only on Query.populate
await p.validate();
await p.remove();
p.toObject();          // plain object for serialization (use this, not spread)

_doc / _schema / _model / _isNew / _modified

FieldDescription
_docThe raw stored object; proxied field reads/writes go here.
_schemaThe NexusSchema for validation/defaults/hooks.
_modelThe owning Model (used for collection access). Circular — do not spread.
_isNewtrue until the first save() insert succeeds. Controls insert vs. update.
_modifiedSet of paths changed since the last save; drives the $set on update.

isModified(path?)

isModified(path?: string): boolean

With a path, whether that path is in _modified. Without, whether anything is modified.

toObject()

toObject(): Record<string, unknown>

Shallow-copy _doc and apply virtual getters (bound to this). Serialize via this — spreading a DocumentInstance proxy leaks internal fields including the circular _model.

toJSON()

toJSON(): Record<string, unknown>

Alias of toObject() for JSON.stringify.

validate()

async validate(): Promise<void>

Run pre('validate') → schema.validate(_doc) → post('validate'). Throws ValidationError on failure.

populate(path)

async populate(path: string): Promise<this>

Resolve a ref/refPath field on this document and assign the hydrated child back onto it. Takes one argument (the path). Nested paths ('a.b') and array refs are supported. Field selection is only available on Query.populate.

save()

async save(): Promise<this>

Run pre('save'), set timestamps, then insert (if _isNew) or update (only modified, non-immutable fields). Defaults are applied before validation on insert. On success, _isNew is cleared and _modified reset. Runs post('save') at the end.

remove()

async remove(): Promise<void>

Run pre('remove'), delete by _id, then post('remove').

Lessons
  • create() builds new instances; hydrate() marks a doc as persisted (save becomes an update). Don't hydrate when you mean create.
  • Always serialize via toObject() — spreading a DocumentInstance proxy leaks internal fields (incl. a circular _model).
  • findById casts a 24-char hex string to ObjectId; the driver won't auto-cast.
  • DocumentInstance.populate(path) takes one arg. Use Query.populate(path, { select }) to select fields on the populated child.
  • FieldDefinition.validate must be { validator, message } (or an array) — a bare function is not accepted.

Query<T> class

class Query<T extends DocumentInstance> {
  constructor(model: Model<T>, op: 'find' | 'findOne', filter: Record<string, unknown>);
  where(path, value): this;
  gt / gte / lt / lte(path, value): this;
  in / nin(path, values): this;
  ne(path, value): this;
  exists(path, yes = true): this;
  sort(spec): this;
  limit(n): this;
  skip(n): this;
  select(fields): this;
  populate(path, opts?): this;
  lean(): this;
  session(session): this;
  async exec(): Promise<T[] | T | null>;
  then(onFulfilled?, onRejected?): Promise<...>;   // thenable
}

A fluent, thenable query builder returned by Model.find/findOne/ findById. It accumulates filter/projection/sort/limit/skip/populate and compiles them to a driver call on then() or exec(). Results are hydrated into DocumentInstances unless lean() is used.

Post.find({ live: true }).sort('-createdAt').limit(10).lean();
Post.findOne({ slug }).populate('author', { select: 'name email' });
Post.findById(id);

where(path, value)

where(path: string, value: unknown): this

Set filter[path] = value directly (overwrites any existing value at that path).

gt / gte / lt / lte(path, value)

gt(path: string, value: unknown): this   // $gt
gte(path: string, value: unknown): this  // $gte
lt(path: string, value: unknown): this   // $lt
lte(path: string, value: unknown): this  // $lte

Comparison operators. Merge into an existing operator object at filter[path], or create one.

in / nin(path, values)

in(path: string, values: unknown[]): this   // $in
nin(path: string, values: unknown[]): this  // $nin

ne(path, value)

ne(path: string, value: unknown): this  // $ne

exists(path, yes = true)

exists(path: string, yes = true): this  // $exists

sort(spec)

sort(spec: string | Record<string, 1 | -1>): this

String form is space-separated, leading - = descending ('-createdAt title'). Object form is used as-is.

limit(n) / skip(n)

limit(n: number): this
skip(n: number): this

select(fields)

select(fields: string): this

Space-separated projection. Leading - = exclude ('name -bio'). When omitted, the query auto-excludes fields declared select: false in the schema.

populate(path, opts?)

populate(path: string, opts: { select?: string; match?: Record<string, unknown> } = {}): this

Resolve a ref/refPath path on the results. select is a space-separated projection applied to the populated child; match adds extra filter conditions to the population query. Supports nested paths ('a.b') and array refs. This is the only place field selection is supported for populate — DocumentInstance.populate(path) takes a single argument.

lean()

lean(): this

Return raw mongo docs (no hydration, no population). Faster and avoids proxy overhead.

session(session)

session(session: unknown): this

Attach a ClientSession to the driver call (for transactions). Pass the same session to all reads/writes inside a transaction(fn).

exec()

async exec(): Promise<T[] | T | null>

Run the query. Runs pre('find'|'findOne') with a mutable { filter, model, op } context (changes to filter are applied), computes the projection (explicit or from select: false fields), executes the driver call, hydrates (unless lean), populates (unless lean), and runs the matching post hook. Returns T[] for find, T | null for findOne.

then(onFulfilled?, onRejected?)

then<R1, R2>(onFulfilled?, onRejected?): Promise<R1 | R2>

The query is thenable — await query is equivalent to await query.exec(). Not a full Promise (no catch/finally).

Projects module

A shared registry of registered projects, each owning its own database. The module keeps the per-project DB on the default connection while the project metadata lives in a separate shared database on its own named connection ('project-info') registered on connectionManager.

import {
  PROJECT_INFO_DB, sanitizeDbName, resolveProjectInfo, connectProjectInfo,
  getProjectInfoCollection, upsertProjectInfo, listProjectInfo, getProjectInfo, closeProjectInfo,
} from '@bhooai/nexus-data';

const info = await resolveProjectInfo(process.cwd());
connectProjectInfo('mongodb://localhost:27017');
await upsertProjectInfo({ ...info, status: 'running', version: '1.0.0' });
const all = await listProjectInfo();
await closeProjectInfo();

PROJECT_INFO_DB

const PROJECT_INFO_DB = 'nexus_projects'

Name of the shared database that stores one record per registered project.

sanitizeDbName(name)

function sanitizeDbName(name: string): string

Derive a MongoDB-safe database name from a project name. Lowercases, replaces non-[a-z0-9_] runs with _, collapses repeated _, trims leading/trailing _, truncates to 63 chars. Falls back to 'project' if the result is empty. 'sample-project' → 'sample_project'.

resolveProjectInfo(root)

async function resolveProjectInfo(root: string): Promise<ProjectInfo>

Read <root>/package.json for the name (falls back to the basename of root, then 'project') and return { name, path: root, dbName: sanitizeDbName(name) }. Never throws on read/parse failure.

connectProjectInfo(uri, options?)

function connectProjectInfo(uri: string, options: { autoIndex?: boolean } = {}): void

Open the shared project-info database on a separate connection registered on connectionManager under the name 'project-info', with name = PROJECT_INFO_DB. The main (default) connection keeps pointing at the per-project DB.

getProjectInfoCollection()

function getProjectInfoCollection(): Promise<Collection<ProjectInfo>>

Return the projects collection on the project-info connection. Call connectProjectInfo first.

upsertProjectInfo(project)

async function upsertProjectInfo(project: ProjectInfo): Promise<ProjectInfo>

Ensure the name unique index, then upsert by name. Stamps updatedAt with new Date().toISOString(). Returns the upserted doc.

listProjectInfo()

async function listProjectInfo(): Promise<ProjectInfo[]>

Ensure indexes, then return every project record sorted alphabetically by name.

getProjectInfo(name)

async function getProjectInfo(name: string): Promise<ProjectInfo | null>

Ensure indexes, then return the single record with that name (or null).

closeProjectInfo()

async function closeProjectInfo(): Promise<void>

If the 'project-info' connection is registered on connectionManager, close it. Call during shutdown.
