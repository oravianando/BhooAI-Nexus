@bhooai/nexus-ads Ads API REST-based Google Ads client with a GAQL query builder.

A small, dependency-light Google Ads client. Uses the Google Ads API REST endpoint googleAds:search with GAQL — no google-ads-api / grpc native dependency. OAuth2 refresh-token access tokens are cached; the HTTP transport is injectable so tests run without live credentials.

Usage

import { createGoogleAds, GaqlBuilder } from '@bhooai/nexus-ads';

const ads = createGoogleAds({
  enabled: true,
  developerToken,
  clientId,
  clientSecret,
  refreshToken,
  loginCustomerId,                       // optional — MCC account
  customerId,
});

const q = new GaqlBuilder()
  .select('campaign.id', 'campaign.name', 'metrics.impressions')
  .from('campaign')
  .where("segments.date >= '2026-08-01'")
  .where("segments.date <= '2026-08-02'")
  .orderBy('metrics.impressions', 'DESC')
  .limit(50)
  .build();

const rows = await ads.search(customerId, q); // paginates via nextPageToken
Why REST, not grpc? Nexus uses the Google Ads googleAds:search REST endpoint (no native google-ads-api / grpc dependency). OAuth2 refresh-token tokens are cached with a 60s margin; developer-token and login-customer-id headers are set by GoogleAdsClient.searchHeaders(); customerId is hyphen-stripped. Tests mock the HTTP transport — no live Google Ads calls.

Client — GoogleAdsClient

class GoogleAdsClient {
  constructor(cfg: GoogleAdsConfig, transport: HttpTransport, apiVersion = 'v17');

  listCampaigns(customerId?: string, limit?: number): Promise<Campaign[]>;

Google Ads REST client. Uses the googleAds:search REST endpoint with GAQL. OAuth2 access tokens are acquired via the refresh-token grant and cached until near expiry (60s safety margin). The HTTP transport is injectable.

search(customerId, query)

async search(customerId: string, query: string): Promise<AdsRow[]>

Run a GAQL query against a customer and return all rows, transparently paginating via nextPageToken. The customerId is hyphen-stripped. Throws [nexus-ads] search failed: HTTP <status> <body> on a non-200 response.

const rows = await ads.search('123-456-7890', q);
// POST https://googleads.googleapis.com/v17/customers/1234567890/googleAds:search

listCampaigns(customerId?, limit?)

async listCampaigns(customerId = this.cfg.customerId, limit = 50): Promise<Campaign[]>

List campaigns on a customer. Runs an internal GAQL query selecting campaign.id, campaign.name, campaign.status, campaign.advertising_channel_type, ordered by campaign.id, then maps each row to a Campaign. Defaults customerId to config.customerId and limit to 50.

campaignMetrics(fromDate, toDate, customerId?, limit?)

async campaignMetrics(
  fromDate: string, toDate: string,
  customerId = this.cfg.customerId, limit = 50,
): Promise<AdsRow[]>

Campaign performance metrics for a date range (YYYY-MM-DD). Runs an internal GAQL query selecting campaign.id, campaign.name, metrics.impressions, metrics.clicks, metrics.cost_micros, metrics.conversions with segments.date >= '<from>' and segments.date <= '<to>', ordered by campaign.id. Returns the raw AdsRow[] (no shape mapping).

const rows = await ads.campaignMetrics('2026-08-01', '2026-08-02');

Query builder — GaqlBuilder

class GaqlBuilder {
  select(...fields: string[]): this;
  from(resource: string): this;
  where(condition: string): this;
  orderBy(field: string, dir: 'ASC' | 'DESC' = 'ASC'): this;
  limit(n: number): this;
  build(): string;
}

GAQL (Google Ads Query Language) builder. Produces queries like:

SELECT campaign.id, campaign.name FROM campaign
WHERE campaign.status = 'ENABLED' ORDER BY campaign.id LIMIT 50

Every chaining method returns this. select(...) takes REST params (one field per argument); multiple calls accumulate. where(...) takes a single full condition string and may be called multiple times (joined with AND).

const q = new GaqlBuilder()
  .select('campaign.id', 'campaign.name', 'metrics.impressions')
  .from('campaign')
  .where("campaign.status = 'ENABLED'")
  .where("segments.date >= '2026-08-01'")
  .where("segments.date <= '2026-08-02'")
  .orderBy('metrics.impressions', 'DESC')
  .limit(100)
  .build();
build() throws build() throws [nexus-ads] GaqlBuilder: FROM resource required if from(...) was never called, and [nexus-ads] GaqlBuilder: at least one field required if select(...) was never called.

select(...fields)

select(...fields: string[]): this

Append fields to the SELECT list (REST params — pass each field as a separate argument). Multiple calls accumulate.

.select('campaign.id', 'campaign.name')
.select('metrics.impressions')      // additive

from(resource)

from(resource: string): this

Set the FROM resource (e.g. 'campaign'). Required — build() throws if unset.

where(condition)

where(condition: string): this

Append a full condition string (e.g. "campaign.status = 'ENABLED'"). Multiple calls are joined with AND. There is no in() helper — pass the full condition yourself.

.where("segments.date >= '2026-08-01'")
.where("segments.date <= '2026-08-02'")
.where("campaign.status = 'ENABLED'")

orderBy(field, dir?)

orderBy(field: string, dir: 'ASC' | 'DESC' = 'ASC'): this

Set the ORDER BY field and direction (default 'ASC'). Only the last call wins.

limit(n)

limit(n: number): this

Set the LIMIT. Omit to leave it unset.

build()

build(): string

Render the final GAQL string. Throws if no FROM resource or no fields were set.

Convenience queries

Two ready-made GAQL builders return query strings (they do not hit the API). Pass them to GoogleAdsClient.search(customerId, q).

campaignsQuery(limit?)

function campaignsQuery(limit = 50): string

Standard campaign-listing GAQL: selects campaign.id, campaign.name, campaign.status, campaign.advertising_channel_type from campaign, ordered by campaign.id, limited to limit (default 50).

const q = campaignsQuery(100);
const campaigns = (await ads.search(customerId, q)).map(rowToCampaign);

campaignMetricsQuery(fromDate, toDate, limit?)

function campaignMetricsQuery(fromDate: string, toDate: string, limit = 50): string

Campaign performance metrics for a date range (YYYY-MM-DD). Selects campaign.id, campaign.name, metrics.impressions, metrics.clicks, metrics.cost_micros, metrics.conversions from campaign, with segments.date >= '<from>' AND segments.date <= '<to>', ordered by campaign.id.

const q = campaignMetricsQuery('2026-08-01', '2026-08-02');
const rows = await ads.search(customerId, q);
Note GoogleAdsClient.listCampaigns and campaignMetrics use the same queries internally (via private helpers). Use these exports when you want the GAQL string itself (e.g. to pass to search with a different customer or to inspect/extend before running).

Transport — fetchTransport

const fetchTransport: HttpTransport

Default fetch-based HTTP transport (Node >= 18); unauthenticated pass-through. It adds no auth — the Authorization (Bearer), developer-token, and login-customer-id headers are added by GoogleAdsClient.searchHeaders(). This helper just forwards method, url, headers, and body to fetch() and returns { status, body, headers }.

const res = await fetchTransport({
  method: 'POST',
  url: 'https://oauth2.googleapis.com/token',
  headers: { 'content-type': 'application/x-www-form-urlencoded' },
  body,
});
