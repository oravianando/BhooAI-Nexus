@bhooai/nexus-safe-goto SafeGoto API Safe external-link navigation for React — noopener + noreferrer, with an optional confirmation dialog.

A React utility for safe external-link navigation. It prevents tab-nabbing (the opened page can't reach back into the opener via window.opener) and referrer leakage (the opened page can't see the admin panel URL) by always opening external links with noopener,noreferrer. An optional confirmation dialog intercepts external links so the user reviews the destination URL before leaving the app. Used by the admin console.

Security rationale noopener prevents the opened page from accessing window.opener (tab-nabbing — a malicious page could otherwise redirect or script the opener tab).
noreferrer prevents referrer leakage — the opened page can't read the Referer header and learn the admin panel URL. Both are always applied by openSafe and by the dialog's "Continue" action.

Usage

import { SafeGotoDialog, SafeGotoLink, safeGoto, interceptExternalLinks } from '@bhooai/nexus-safe-goto';

// 1. Mount the dialog ONCE at the app root.
function App() {
  return (
    <>
      <SafeGotoDialog />
      <Routes />
    </>
  );
}

// 2a. Use the link component (renders an <a>).
<SafeGotoLink href="https://openai.com">OpenAI</SafeGotoLink>

// 2b. Or trigger programmatically.
<button onClick={() => safeGoto("https://openai.com")}>Go</button>

// 2c. Or intercept ALL external <a> clicks via a delegated handler.
<div onClick={interceptExternalLinks}>
  {userGeneratedContentWithAnchors}
</div>
Fallback when no dialog is mounted If SafeGotoDialog is not mounted, safeGoto(url) falls back to openSafe(url) — a direct window.open(url, '_blank', 'noopener,noreferrer'). The link still opens safely (noopener + noreferrer), just without the confirmation prompt. Mount the dialog at the app root to get the confirmation UX.

Registry

A module-level singleton holds the dialog's state setter. SafeGotoDialog registers on mount and unregisters on unmount; safeGoto calls the registered setter to show the dialog. You normally don't call these directly — the dialog wires them for you.

registerSafeGoto(setter)

function registerSafeGoto(setter: (nav: { url: string; label: string; message?: string } | null) => void): void

Register the dialog's state setter. Called by <SafeGotoDialog /> on mount via useEffect. After this, safeGoto() will route requests to the mounted dialog instead of opening directly.

unregisterSafeGoto()

function unregisterSafeGoto(): void

Clear the registered setter. Called by <SafeGotoDialog /> on unmount (the useEffect cleanup). After this, safeGoto() falls back to openSafe.

Navigation

safeGoto(url, opts?)

function safeGoto(url: string, opts: SafeGotoOptions = {}): void

Trigger the safe-goto confirmation dialog for an external URL. If a dialog is mounted (via registerSafeGoto), it opens the modal with the URL and a "Stay here" / "Continue to {hostname}" choice. If no dialog is mounted, falls back to window.open(url, '_blank', 'noopener,noreferrer') directly.

safeGoto("https://openai.com");
safeGoto("https://openai.com", { label: "OpenAI", message: "You are leaving the admin console." });

openSafe(url)

function openSafe(url: string): void

Open a URL safely — always noopener + noreferrer. This is the primitive the dialog's "Continue" button calls, and the fallback safeGoto uses when no dialog is mounted. Use it directly when you want to open an external link without the confirmation prompt but still want the security protections.

openSafe("https://openai.com"); // window.open(url, '_blank', 'noopener,noreferrer')

isExternalUrl(url)

function isExternalUrl(url: string): boolean

True if the URL's origin differs from window.location.origin; false on parse error. Resolves relative URLs against the current page before comparing, so "/admin" is internal while "https://other.com/x" is external.

isExternalUrl("https://openai.com");   // true
isExternalUrl("/admin/users");        // false
isExternalUrl("not a url");           // false (parse error)

interceptExternalLinks(e)

function interceptExternalLinks(e: React.MouseEvent): void

A click handler that intercepts external <a> clicks and routes them through safeGoto. Attach it to a container element (delegated handler) and any http(s) external anchor inside will be intercepted. Internal links, non-anchor clicks, and non-http(s) links (e.g. mailto:, #anchors) pass through untouched.

<div onClick={interceptExternalLinks}>
  {renderedMarkdownWithAnchors}
</div>

Logic: finds the closest <a> ancestor of the click target; if its href starts with http:// or https:// and isExternalUrl(href) is true, calls e.preventDefault() then safeGoto(href). Otherwise lets the browser handle the click normally.

Components

SafeGotoDialog

function SafeGotoDialog(): JSX.Element | null

The confirmation dialog. Mount once at the app root. On mount it calls registerSafeGoto(setPending); on unmount it calls unregisterSafeGoto(). When safeGoto() fires, the dialog receives the pending navigation and renders an overlay modal with the destination URL, a security warning, and two actions:

  • Stay here — cancels (clears pending state, closes the dialog).
  • Continue to {hostname} → — calls openSafe(url) then closes.

Returns null when there's no pending navigation, so it renders nothing until triggered. Clicking the overlay backdrop cancels. CSS classes used: safe-goto-overlay, safe-goto-dialog, safe-goto-icon-wrap, safe-goto-icon, safe-goto-body, safe-goto-title, safe-goto-msg, safe-goto-url, safe-goto-shield, safe-goto-warning, safe-goto-actions, glass-chip-btn, glass-btn-primary.

import SafeGotoDialog from '@bhooai/nexus-safe-goto'; // default export

function App() {
  return (
    <>
      <SafeGotoDialog />
      <Router />
    </>
  );
}

SafeGotoLink

function SafeGotoLink(props: {
  href: string;
  children: React.ReactNode;
  className?: string;
}): JSX.Element

A safe external link. Renders an <a> whose onClick calls e.preventDefault() then safeGoto(href), so the browser's default navigation is replaced with the confirmation dialog. The href attribute is still set (so middle-click / right-click / copy-link still work, and the anchor is crawlable). Default class is safe-goto-link; pass className to override. The title attribute is set to "Open {hostname} in a new tab (safe)".

PropTypeDefaultDescription
hrefstring—Destination URL.
childrenReact.ReactNode—Link content.
className?string'safe-goto-link'CSS class for the <a>.
 
<SafeGotoLink href="https://openai.com">OpenAI</SafeGotoLink>
<SafeGotoLink href="https://openai.com" className="my-link">OpenAI</SafeGotoLink>
