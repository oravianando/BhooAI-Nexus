API Reference

HTTP Endpoints Complete reference of every route the inbuilt NexusServer exposes, organized by module. ~73 endpoints across core, auth, admin, cluster, AI, and payments.

The framework boots a custom HTTP server on node:http with a trie router and a middleware pipeline. Every request flows through the global middleware stack below before being dispatched to a module handler.

Global middleware

Applied to all requests, in order:

MiddlewareSourceRole
securityHeaders()nexus-authHSTS, X-Content-Type-Options, frame-options, referrer-policy, CSP-ready
cors({ origin, credentials })nexus-authPer-origin allow-list, preflight handling, credentialed cookie support
bodyParser(bodyLimit)nexus-coreJSON / urlencoded / multipart parsing into ctx.body + ctx.state.files
csrf({ trustedOrigins })nexus-authDouble-submit CSRF on all unsafe methods (POST/PUT/DELETE/PATCH)
rateLimit({ windowMs, max })nexus-auth300 requests / minute per IP (in-memory; Redis backend in nexus-cache)
 
const server = new NexusServer({
  router,
  bodyLimit: config.server.bodyLimit,
  middleware: [
    securityHeaders(),
    cors({ origin: config.cors.origins, credentials: true }),
    bodyParser(config.server.bodyLimit),
    csrf({ trustedOrigins: config.cors.origins }),
    rateLimit({ windowMs: 60_000, max: 300 }),
  ],
  onError: (err, ctx) => ({ error: { code: err.code, message: err.message } }),
});
Auth shorthand In the tables below: None = no auth; CSRF = requires x-csrf-token header matching the nexus_csrf cookie from GET /csrf-token; JWT = requires Authorization: Bearer <accessToken> (or the auth cookie); Signature = verified by the provider's webhook secret, not CSRF/JWT; admin = the JWT subject must carry the admin role.

Calling an unsafe endpoint

// 1. fetch a CSRF token (sets the nexus_csrf cookie)
const r = await fetch('/csrf-token', { credentials: 'include' });
const { token } = await r.json();

// 2. send it back on every POST/PUT/DELETE
await fetch('/echo', {
  method: 'POST',
  credentials: 'include',
  headers: { 'Content-Type': 'application/json', 'x-csrf-token': token },
  body: JSON.stringify({ hello: 'nexus' }),
});
Two rules to remember All unsafe methods (POST / PUT / DELETE / PATCH) require a CSRF token from GET /csrf-token. All /admin/* routes require a JWT Bearer token (or the auth cookie) whose subject carries the admin role. Webhooks (/payments/webhook/:provider) are the only exception — they are verified by provider signature, never CSRF or JWT.
